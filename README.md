# ShopProject

Учебный многостраничный HTML/CSS-сайт интернет-магазина аксессуаров для рабочего места. Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

GitHub Pages: https://shebaketerayo.github.io/kr1-html-css-shop/

## Структура

- `index.html` — главная страница;
- `catalog.html` — каталог;
- `product-keyboard.html`, `product-mouse.html`, `product-mat.html` — карточки товаров;
- `order.html` — оформление заявки;
- `contacts.html` — контакты;
- `css/style.css` — общие стили;
- `js/main.js` — модальное окно и проверка формы;
- `images/` — изображения товаров.

## Технологии

HTML5, CSS3, минимальный JavaScript.
